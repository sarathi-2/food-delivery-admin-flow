# CraveAdmin — Food Delivery Platform Admin Flow

A responsive React + Vite admin dashboard prototype covering the 8 requested modules:
1. Dashboard & Analytics
2. Order Management
3. Restaurant & Menu
4. Delivery Partners
5. Customers
6. Payments & Finance
7. Offers & Promotions
8. Support, Reports & Settings

## Run locally
1. Install Node.js (18+ recommended).
2. Extract the ZIP and open this folder in VS Code.
3. In a terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Build
```bash
npm run build
```

## Included interactions
- Sidebar navigation across all 8 modules
- Responsive layouts for desktop, tablet and mobile
- Search and status filters for operational tables
- Order details modal and quick status progression
- Add restaurant/partner/order and create/edit offer modal flows
- Offer creation, deletion and campaign status display
- Finance settlement review and report export feedback
- Support ticket resolution feedback and quick settings toggles
- Revenue and peak-hour charts

## Notes
This is a frontend demo with sample/mock data. It does not connect to a backend, payment gateway, live maps, real customer records or authentication. Forms and action buttons demonstrate the admin UI flow; connect APIs and add server-side validation before production use.
